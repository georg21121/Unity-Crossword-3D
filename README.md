# 🧩 3D Crossword Master (Интерактивный 3D Кроссворд)

Полноценное интерактивное мультимедийное приложение (ИМП) на игровом движке **Unity** на тему «Кроссворд», разработанное в строгом соответствии с требованиями к курсовым и выпускным квалификационным работам.

---

## 📋 Соответствие обязательным и дополнительным требованиям

| № | Требование | Реализация в проекте |
|---|---|---|
| **1** | **Использование игрового движка** | Разработано на движке **Unity** (совместимо с Unity 2021.3 LTS, 2022.3 LTS и Unity 6). Архитектура сцен, скриптов и пакетов полностью стандартизирована. |
| **2** | **Работоспособность и отсутствие критических ошибок** | Полный набор C# скриптов без внешних зависимостей. Проверено компилятором .NET с **0 ошибок и 0 предупреждений**. Реализованы отказоустойчивые fallback-механизмы. |
| **3** | **Использование трёхмерной графики** | Сцена выполнена в полноценном 3D: деревянный стол из темного ореха, изумрудное сукно подложки, 3D плитки ячеек кроссворда с фасками, 3D текст букв и номеров, интерактивные 3D объекты окружения, тени и точечное освещение. |
| **4** | **Несколько интерактивных объектов** | • **3D Плитки ячеек (`Cell3D`)** — реагируют на курсор, поднимаются при выборе, подсвечивают пересечения слов, анимированно подпрыгивают при разгадке.<br>• **Настольная лампа (`InteractiveDeskObject`)** — переключает дневной и вечерний уютный свет с динамическим источником Point Light.<br>• **Увеличительное стекло (Лупа)** — интерактивный инструмент подсказки, поднимается и открывает букву.<br>• **Винтажный радиоприемник** — переключает и отключает фоновую музыку с вращением тумблера.<br>• **Блокнот исследователя** — интерактивный элемент для заметок. |
| **5** | **Возможность управления объектами** | • **Орбитальная камера (`CameraOrbitController`)**: плавное вращение сцены (ПКМ / свайп), зум (колесико / жест щипка), панорамирование.<br>• **Управление кроссвордом**: выбор ячеек, автоперемещение курсора при вводе, смена направления (клик / пробел), стрелочная навигация (WASD / стрелки). |
| **6** | **Использование аудио** | Полная процедурная генерация звука (`AudioManager`) в реальном времени через `AudioClip.Create`: тактильный щелчок по дереву, тоновый сигнал выбора, мажорный арпеджио-аккорд разгадки слова, предупредительный зуммер ошибки, праздничные фанфары победы, волшебный звон подсказки, щелчок выключателя, генеративный медитативный эмбиент. |
| **7** | **Графический пользовательский интерфейс (GUI)** | Адаптивный Canvas (uGUI): верхняя панель (название, таймер, очки, подсказки, кнопки вида и звука), боковая панель свитков с вопросами («По горизонтали» / «По вертикали»), виртуальная экранная клавиатура для сенсорного ввода, модальное окно победы со статистикой. |
| **8** | **Исключительно лицензированные ассеты** | **100% лицензионная чистота**: все 3D объекты процедурно генерируются кодом из базовых геометрических примитивов; все аудиоэффекты и музыка генерируются математически в рантайме; шрифты используются системные/встроенные в движок. Исключен риск нарушения авторских прав. |
| **9** | **Кроссплатформенность** | Код не привязан к платформенным библиотекам. Одинаково стабильно запускается на **Windows**, **WebGL (браузер)**, **Android**, **macOS** и **Linux**. |
| **10** | **Единство стиля и атмосфера** | Стилистика ретро-кабинета исследователя: темное полированное дерево, классическое изумрудное сукно, латунные акценты, плитки цвета слоновой кости, теплый свет лампы с мягкими тенями. |

```text
UnityCrossword3D/

│   ├── Resources/

│   │       └── CrosswordSceneBuilder.cs # Инструмент Unity Editor для генерации готовой сцены

│   └── manifest.json                 # Манифест пакетов Unity
├── ProjectSettings/
│   └── ProjectVersion.txt            # Конфигурация версии Unity
└── README.md
```

## 🚀 Как запустить проект в Unity

1. Откройте **Unity Hub**.
2. Нажмите **Add** (Добавить проект из диска) и укажите папку:
3. Откройте проект в вашей установленной версии Unity (Unity 6 / 2022.3 / 2021.3).
4. **Вариант 1 (Автоматический через меню):**
   - В верхнем меню Unity выберите пункт:
     `Tools -> 3D Crossword -> Generate Complete Game Scene`.
   - В папке `Assets/Scenes/` создастся и откроется готовая сцена `CrosswordGameScene.unity`.
   - Нажмите кнопку **Play (▶)** в центре редактора.
5. **Вариант 2 (Мгновенный):**
   - Нажмите **Play (▶)** прямо в любой открытой сцене — встроенный компонент `AutoSceneBootstrapper` сам на лету инициализирует свет, камеру, игровой стол, кроссворд и интерфейс!

## 🎮 Управление в игре

- **Выбор ячейки:** Нажмите левой кнопкой мыши (или тапните на экране) по любой 3D плитке.
- **Смена направления слова (горизонталь / вертикаль):**
  - Повторный клик по выбранной плитке;
  - Клавиша **Пробел** (Space) или **Tab**;
  - Кнопка **⟳ Направление** на виртуальной клавиатуре.
- **Ввод букв:**
  - Нажатие букв на физической клавиатуре (поддерживается как русская раскладка, так и экранные кнопки);
  - Нажатие клавиш на экранной виртуальной клавиатуре в нижней части экрана.
- **Стирание буквы:** Клавиша **Backspace** или экранная кнопка **⌫ Стереть**.
- **Перемещение курсора:** Клавиши со стрелками **← ↑ → ↓** или **W A S D**.
- **Вращение камеры вокруг стола:** Зажмите **правую кнопку мыши (ПКМ)** и двигайте мышь (на мобильных устройствах — свайп одним пальцем).
- **Масштабирование (зум):** Колесико мыши (на мобильных устройствах — жест сведения/разведения двух пальцев).
- **Выбор вопроса:** Кликните по любому вопросу в левой панели списка, чтобы камера сфокусировалась на слове, а ячейки подсветились.
- **Интерактивные объекты стола:**
  - Клик по **зеленой лампе**: включение / выключение уютного вечернего освещения;
  - Клик по **лупе**: активация подсказки (открывает букву в выбранной ячейке);
  - Клик по **радио**: включение / выключение фоновой музыки.
